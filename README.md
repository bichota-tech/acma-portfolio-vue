# ACMA Portfolio Vue

---

## 🇪🇸 Español

Aplicación de portfolio personal desarrollada con Vue.js 3, construida con las últimas tecnologías web modernas.

### 🚀 Tecnologías

- **Vue 3** - Framework progresivo de JavaScript
- **Vite** - Build tool y dev server ultra rápido
- **Vue Router** - Enrutamiento oficial para Vue.js
- **Pinia** - Sistema de gestión de estado para Vue
- **Vitest** - Framework de testing unitario
- **ESLint + Oxlint** - Linting de código
- **Prettier** - Formateador de código

### 📋 Requisitos Previos

- Node.js `^20.19.0` o `>=22.12.0`
- npm (incluido con Node.js)

### 🛠️ Instalación

```sh
npm install
```

### 💻 Desarrollo

Inicia el servidor de desarrollo con hot-reload:

```sh
npm run dev
```

### 🏗️ Build y Preview

Genera la versión de producción:

```sh
npm run build
```

Previsualiza la versión de producción localmente:

```sh
npm run preview
```

### 🧪 Tests

Ejecuta los tests unitarios con Vitest:

```sh
npm run test:unit
```

### 🔍 Lint y Formato

Ejecuta el linter (Oxlint + ESLint) con corrección automática:

```sh
npm run lint
```

Formatea el código fuente con Prettier:

```sh
npm run format
```

### 🚀 Despliegue

Este proyecto está desplegado en **Firebase Hosting**. La URL pública se añadirá próximamente.

## 🇬🇧 English

Personal portfolio application built with Vue.js 3, using the latest modern web technologies.

### 🚀 Tech Stack

- **Vue 3** - Progressive JavaScript framework
- **Vite** - Lightning-fast build tool and dev server
- **Vue Router** - Official router for Vue.js
- **Pinia** - State management for Vue
- **Vitest** - Unit testing framework
- **ESLint + Oxlint** - Code linting
- **Prettier** - Code formatter

### 📋 Prerequisites

- Node.js `^20.19.0` or `>=22.12.0`
- npm (bundled with Node.js)

### 🛠️ Installation

```sh
npm install
```

### 💻 Development

Start the development server with hot-reload:

```sh
npm run dev
```

### 🏗️ Build & Preview

Build for production:

```sh
npm run build
```

Preview the production build locally:

```sh
npm run preview
```

### 🧪 Tests

Run unit tests with Vitest:

```sh
npm run test:unit
```

### 🔍 Lint & Format

Run the linter (Oxlint + ESLint) with auto-fix:

```sh
npm run lint
```

Format source code with Prettier:

```sh
npm run format
```
